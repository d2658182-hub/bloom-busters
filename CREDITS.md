# Credits & Licenses

Every asset in this game is a real downloaded file (no art generated by code).
100% of the files are freely licensed (CC0 / Public Domain / CC-BY with attribution).

## Kenney.nl (CC0 1.0) — https://kenney.nl
- **Nature Kit** — placeholder reference only (unused art).
- **Game Icons** — UI star/trophy icons (unused art).
- **Particle Pack** — particle sprites (`star_*`, `spark_*`, `circle_*`, `magic_*`)
  used for burst effects, confetti and ambient magic dust.
- **Music Jingles** — game-over sting (`jingles_STEEL00.ogg`).
- **Interface Sounds** — UI clicks, drop, error, confirmation SFX.
- **Impact Sounds** — match/destroy impact SFX.
- **Animal Pack** — round animal sprites (elephant, giraffe, hippo, monkey,
  panda, parrot, penguin, pig, rabbit, snake) — the “Creatures” piece family.
- **Puzzle Pack 2** — colored gem tiles in 8 colors — the “Crystals” piece family.
- **Game Icons** — white rune icons (star, trophy, medal, arrows, plus/minus,
  lock/unlock, music on/off, cross/check…) tinted per level — the “Runes” piece family.
- **Domino Pack** — domino tiles (Stars / Hearts / Gingerbread pips) — the
  “Dominoes” piece family (number + motif rules).
- **RPG Urban Pack / UI Pack** — unused.
